## Architecture (as frozen, deltas vs v0.3)

- **A — StateAdd:** `state_mlp = MLP(16→256→8·256)` → reshape `[8,256]`;
  `q_i' = q_i + qmask_i · tanh(α_i) · u_i`, `α ∈ R^8` zero-init. Queries stay learnable.
- **B — 4/4 split:** `cond_qmask` buffer = `[1,1,1,1,0,0,0,0]` — queries 0-3 conditioned,
  4-7 never see state (02 §3 recipe, order per its §5 pseudocode).
- **C — predictor queries:** P=16 learned queries concatenated with the 8 output queries
  through the SAME PerceiverFuse blocks over the same context, state K/V column masked for
  all 24 rows. PerceiverFuse has no query self-attention (queries independent per-row in
  `CrossAttention`), so read-only isolation is structural — verified numerically (T3).
  Predictor queries receive `pred_state(s) + pred_act(action_chunk)` broadcast-added.
  Loss reads predictor outputs after the final (2nd) block only.
- **D — objective:** target = RAW frozen ViT-B/16 per-cam patch-pooled features `[K,768]`
  of the cache row at `t + h_eff` (stop-grad by construction — comes straight from the
  fp16 patch cache, same frozen backbone the encoder consumes). Head:
  `pred_head = MLP(256→1024→K·768)` on the mean-pooled predictor outputs; loss =
  `mean_cams(1 − cos)`; total = v0.3 loss + `lamb_aux · aux`, `lamb_aux` default 0.05.
- **E — anti-shortcut stack** (all config-gated, defaults ON): per-dim `F.dropout(p=0.2)`;
  Gaussian noise σ = 10^(−SNR/20) on the normalized state (default SNR 20 dB → σ=0.1);
  CFG whole-condition dropout p cosine-annealed 0.5→0.1 over the first half of
  `total_steps` then constant, null = learned `[8,256]` token; zero-init gates.
- v0.3 losses (`inv + λ_sig·sig + λ_patch·patch`) kept verbatim; `z_from_s`, `z_full`,
  sigreg paths use plain (unconditioned) queries exactly as v0.3.

## Design choices where the docs left options open (each recorded per task brief)

1. **v0.3 loss stack kept unchanged** (inv + sig + patch) with the aux ADDED. Recorded
   risk: `pred_s(z_from_v)` becomes partially copyable once gates open (01 §6.3).
   Mitigants: condition dropout makes it non-copyable on 10-50% of samples; D2 is the
   watchdog; first lever on a D2 collapse flag = drop the `pred_s` term.
2. **Horizon snapping:** cache is stride-5 at 20 Hz, so `h_eff = round(h/5)·5` (min 5):
   h=6 → 5 ticks (0.25 s), h=16 → 15 ticks (0.75 s) — inside 03's {~0.3 s, ~0.8 s} band.
   The action chunk covers exactly `t..t+h_eff` (coherent with the target frame).
3. **Aux target = RAW 768-d backbone features** (hard-frozen), NOT the EMA `tgt_v`
   projection — 03 §4a: frozen external targets need no EMA; one target family only.
4. **P→target mapping:** 03 gives no per-token matching for our shapes; chose mean-pool
   over the 16 predictor outputs → MLP projector → K×768, per-cam cosine (Octo readout
   pooling + FRAPPE projector+cosine recipe).
5. **Predictor conditioning ungated and never condition-dropped:** the zero-init-gate
   mandate (01 §6.1) covers state paths into the policy-facing z; the predictor is
   training-only machinery (GeoPredict pattern) and must ALWAYS see state+actions so the
   residual the loss chases is scene content. Per-dim dropout + Gaussian noise DO apply
   (shared regularized state `s_reg` feeds both new paths). v0.3 loss paths get clean
   state, exactly as v0.3.
6. **Predictor K/V:** same context with the state column masked for predictor rows too —
   state reaches the predictor only via query injection (01 §6.2: state out of the value
   path everywhere).
7. **Condition-dropout null at the injection level** (learned `[8,256]` token replacing
   `u = state_mlp(s)`), not at the raw-state level; flows through the same tanh(α) gates,
   so α=0 equivalence is preserved trivially.
8. **Actions used raw** (already normalized to [−1,1] in the lerobot data, 12-D);
   end-of-episode: future row clamped to the episode's last cached frame (the E4
   `min()` pattern from `diffusion_policy/dataset/lerobot_dataset.py`), action chunk
   padded by repeating the last action.
9. **`embed_vision` (gates battery) returns the CONDITIONED pooled latent** at learned α
   (eval: no dropout/noise/cond-drop) so the v0.3 `gates()` battery runs unmodified;
   interpretation of `zv_r2_state` on conditioned tokens defers to D2.
10. **Equivalence reference** = `MMPerceiverMCPatch.fuse(ctx, mask_state, pool=False)` —
    the pretrain-side ground truth of what `kepler_encoder.forward_set()` computes
    (masked state token ≡ excluded state token under softmax masking; the downstream
    ckpt-loading path `proj_v/fuse/mod[0]/cam_emb` is untouched by this build).
11. **Detector D1 measured on encoder outputs + aux loss** (no policy head exists at
    pretrain time): relative L2 latent deltas per query subset + the 03 aux-health sweep
    (null-vision must move the aux; also permuted-actions as an action-use check). D2 =
    RidgeCV state→z per-token R², episode-held-out. The z→object-pose floor from 02 is
    NOT computed (no object pose in the cache) — flagged in the printout. Thresholds
    (vision-delta <0.02 ∧ state-delta >0.10 → SHORTCUT; cond R² ≥0.9 → COLLAPSE) are
    02's proposals, printed alongside raw numbers.
